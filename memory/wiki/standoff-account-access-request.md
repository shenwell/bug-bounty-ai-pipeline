# Standoff365 — preliminary progress report (§7)

Use when registration or account access is structurally blocked and hunting cannot proceed without triager help.

## Paste checklist

1. Title states access is blocked (not a vulnerability claim).
2. List completed recon / analysis steps with evidence paths.
3. Blocker paragraph — factual: which registration step fails and why.
4. Table of requested test accounts (role, purpose, same tenant when possible).
5. Ask triager to reply in report comments.

Draft location: `data/dossiers/<slug>/reports/preliminary-progress-report.md`  
Submit paste: `data/dossiers/<slug>/reports/submit/*-paste.md`

**Human gate:** operator submits on the platform — agent prepares paste only.
