# Portfolio runtime data

Generated by `/portfolio` (Phase 1). **Not committed** except this README.

| Path | Purpose |
|------|---------|
| `contracts.yaml` | Discovered and scored programs |
| `disclosed-reports.yaml` | Platform disclosed reports cache |
| `dossiers/<slug>/` | Contract dossiers (Phase 1 output, Phase 2 input) |
| `snapshots/` | Raw HTML snapshots from discover |
| `monitor/` | New-program monitor state |
| `artifacts/` | Portfolio build artifacts |

Copy `config/portfolio.yaml.example` → `config/portfolio.yaml` and
`config/.env.portfolio.example` → `config/.env.portfolio` (or repo `.env`)
before running Phase 1.
